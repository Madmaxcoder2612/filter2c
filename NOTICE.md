# Prior art and independence

All code, tests, documentation and examples in this repository were written from scratch by the author. Nothing was copied, ported or closely paraphrased from another project.

## What the work is based on

- **Mathematics.** The Butterworth magnitude response, the bilinear transform and the biquad (second-order section) structure are textbook results. The test `test_c_gain_matches_analytic_butterworth` checks the generated code against the closed-form formula, which is independent of any library.
- **Official documentation.** SciPy's published documentation for `scipy.signal.butter` and `scipy.signal.sosfilt`, used as a user of the library.

## Other projects (ideas only, no code read or copied)

Other projects exist that run filters on microcontrollers or generate filter code. They were looked at only as a list of names, to avoid clashing with them and to see what already exists. Their source code was not read.
